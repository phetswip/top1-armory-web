CONNECT CLAUDE

เชื่อม Claude กับคลังแสง

ตั้งค่าครั้งเดียวด้วยคีย์นักเรียน แล้ว Claude ของคุณจะเปิดดูทุกสไตล์ในคลังได้ — ดูคลิปตัวอย่างทีละเฟรม ถอดเสียง จับจังหวะ แล้วทำแบบเดียวกันให้แบรนด์คุณ

1ใส่คีย์นักเรียน

คีย์ได้จากคอร์ส TOP 1 HollyWood หน้าตาแบบ T1-XXXX-XXXX-XXXX — 1 คน 1 คีย์ ห้ามแชร์ให้คนอื่น

2ลิงก์เชื่อมต่อของคุณ

ลิงก์นี้มีคีย์ของคุณอยู่ข้างใน — ใช้กับ Claude ของคุณเท่านั้น

claude.ai / แอป Claude

  1. เปิด Settings (การตั้งค่า) → Connectors
  2. กด Add custom connector
  3. ช่อง Name ใส่ TOP 1 คลังแสง
  4. ช่อง URL วาง ลิงก์เชื่อมต่อ ด้านบน → กด Add
  5. ในแชทใหม่ กดปุ่มเครื่องมือ แล้วเปิดใช้ TOP 1 คลังแสง
เปิดหน้า Connectors

Claude Code (ทำคลิปจริง)

  1. เปิด Terminal ในโฟลเดอร์ ชุดเริ่มต้น TOP 1
  2. วางคำสั่งนี้ครั้งเดียว แล้วกด Enter
เปิด Claude Code แล้วพิมพ์ /mcp — ต้องเห็น top1-armory ขึ้นว่าเชื่อมแล้ว

3ลองสั่ง Claude

ส่งข้อความนี้ในแชทที่เปิดคลังแสงแล้ว — Claude ควรตอบเป็นรายการสไตล์ในคลัง
ใช้คลังแสง TOP 1 ดูรายการสไตล์ทั้งหมด (list_styles) แล้วแนะนำ 3 สไตล์ที่เหมาะกับสินค้าของฉัน
เลือกสไตล์ในคลัง →
เจอสไตล์ที่ชอบ กดปุ่ม ทำคอนเทนต์แบบนี้ ที่การ์ด จะได้ข้อความสั่งงานพร้อมใช้ของสไตล์นั้น

ติดปัญหา?

  1. คีย์ใช้ไม่ได้ — เช็กว่าคัดลอกครบทุกตัว (ไม่มีช่องว่าง) ถ้ายังไม่ได้ ติดต่อทีมงาน TOP 1 HollyWood
  2. Claude ขอให้ล็อกอิน / กด Connect / ขึ้นว่ายืนยันตัวตนไม่สำเร็จ — แปลว่าคีย์ในลิงก์ผิด ถูกปิด หรือหมดอายุ (คลังแสงไม่มีหน้าล็อกอิน) → กด ทดสอบการเชื่อม ด้านบน แล้วลบ connector เดิมใน Claude และเพิ่มใหม่ด้วยลิงก์ล่าสุด
  3. Claude ไม่เห็นเครื่องมือ — เช็กว่าเปิดใช้ TOP 1 คลังแสงในแชทนั้นแล้ว หรือลบ connector แล้วเพิ่มใหม่ด้วยลิงก์ล่าสุด
  4. เปลี่ยนเครื่อง — ใช้คีย์เดิมได้ แค่ทำขั้นตอนเชื่อมอีกครั้ง
  5. ห้ามแชร์คีย์ — ระบบบันทึกการใช้งานของแต่ละคีย์ คีย์ที่ถูกแชร์อาจถูกปิด
