เชื่อม แอป Claude กับคลังแสง

ทำครั้งเดียวบนคอมพิวเตอร์ — จากนั้นกด "ทำคอนเทนต์แบบนี้" ที่สไตล์ไหนก็ได้ แอป Claude จะเปิดในโฟลเดอร์ชุดเริ่มต้นของคุณพร้อมคำสั่ง แค่กด Enter

ก่อนเริ่ม (ครั้งเดียว)

  1. ติดตั้ง แอป Claude บนคอม (Mac หรือ Windows) แล้วล็อกอิน — ดาวน์โหลดแอป Claude
  2. ดาวน์โหลด ชุดเริ่มต้น จากหน้า คอร์สของฉัน → ไฟล์ประกอบคอร์ส แล้วแตกไฟล์ .zip (เก็บไว้ที่ Desktop ก็ได้)
กำลังเช็กบัญชีของคุณ…

ติดปัญหา?

  1. กดแล้วแอปไม่เปิด — ติดตั้งหรืออัปเดตแอป Claude แล้วลองใหม่ · ถ้าเบราว์เซอร์ถามว่าจะเปิดแอป Claude ไหม ให้กด "เปิด" · หรือกด "คัดลอกข้อความ" แล้ววางเองในแอป (แท็บ Code → เลือกโฟลเดอร์ชุดเริ่มต้น)
  2. แอปเปิดผิดโฟลเดอร์ / หาไฟล์ไม่เจอ — วางที่อยู่โฟลเดอร์ใหม่ (ต้องเป็นโฟลเดอร์ที่แตกไฟล์แล้ว ข้างในมี CLAUDE.md) แล้วกดเชื่อมอีกครั้ง
  3. Claude บอกว่ายังไม่เห็นเครื่องมือคลังแสง — ปิดแชทนั้น แล้วเริ่มแชทใหม่ (แชทใหม่ถึงจะโหลดเครื่องมือ) · ถ้าแอปขึ้นปุ่มให้ลงชื่อเข้าใช้ (Authenticate) ของ top1-armory ห้ามกด — แปลว่าคีย์ใช้ไม่ได้ ให้กด "ทดสอบคีย์" · ถ้ายังไม่ได้ กดเชื่อมคลังแสงอีกครั้ง
  4. คีย์ใช้ไม่ได้ — กด "ทดสอบคีย์" ถ้าขึ้นว่าหมดอายุหรือถูกปิด ติดต่อทีมงาน TOP 1 HollyWood
  5. เปลี่ยนคอม / ย้ายโฟลเดอร์ — ทำหน้านี้ใหม่อีกครั้ง ใช้คีย์เดิมได้
  6. ห้ามแชร์คีย์ — ระบบบันทึกการใช้งานของแต่ละคีย์ คีย์ที่ถูกแชร์อาจถูกปิด
