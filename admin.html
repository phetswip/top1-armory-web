ออกคีย์ · นักเรียน · บทเรียน · ไฟล์คอร์ส · สไตล์ · การใช้งาน

สมัครครั้งแรก: สร้างบัญชีด้วยอีเมลของคุณ → ยืนยันอีเมล (ถ้าระบบส่งไป) → เข้าสู่ระบบ → ใส่รหัสตั้งค่าเพื่อยืนยันว่าเป็นเจ้าของ
เข้าด้วยโทเคนแอดมิน (สำรอง)
ใช้โทเคนเดียวกับรหัสตั้งค่า — เก็บไว้เฉพาะแท็บนี้ ปิดแท็บแล้วหายเอง

ยืนยันสิทธิ์เจ้าของ

บัญชี ยังไม่ใช่แอดมิน — ใส่ รหัสตั้งค่า (setup code) ที่ได้ตอนติดตั้งระบบ เพื่อผูกบัญชีนี้เป็นเจ้าของคลังแสง (ทำครั้งเดียว)

สร้างคีย์ใหม่

ออกคีย์ให้นักเรียนที่จ่ายแล้ว — นักเรียนใช้คีย์นี้ลงทะเบียนเข้าเรียน และเชื่อม Claude กับคลังแสง (ปิด/ลบได้ทุกเมื่อ) · ปุ่ม ข้อความ = คัดลอกคีย์ + ลิงก์ลงทะเบียน พร้อมส่ง

สร้างหลายคีย์

วางรายชื่อ บรรทัดละ 1 คน (สูงสุด 200)

คีย์ทั้งหมด

นักเรียน

นักเรียนลงทะเบียนเองด้วยคีย์ที่หน้าลงทะเบียน · ปิดสวิตช์ = พักการเรียน (เปิดคืนได้) · ความคืบหน้า = บทที่เรียนจบ / บทที่เผยแพร่

บทเรียน

กด แก้ไข เพื่อใส่วิดีโอ โน้ต และไฟล์แนบ · เผยแพร่ = นักเรียนเห็นบทนี้ · ดูฟรี = คนที่ยังไม่สมัครก็ดูได้ · ลูกศร = เลื่อนลำดับ

อัปโหลดไฟล์คอร์ส

ไฟล์ที่นักเรียนดาวน์โหลดได้ในหน้า คอร์สของฉัน → ไฟล์ประกอบคอร์ส · ไฟล์ zip ชุดเริ่มต้น TOP 1 ใส่ที่นี่
ใช้ไฟล์ TOP1-HOLLYWOOD-ชุดเริ่มต้น.zip ที่เพิ่งสร้างใหม่ด้วย tools/pack_starter_kit.sh เท่านั้น (สคริปต์เอา .mcp.json / .claude/settings.local.json ออก และคืนโฟลเดอร์ ความจำลูกค้า เป็นแบบฟอร์มเปล่าให้เอง) — ห้าม zip โฟลเดอร์เอง ไม่อย่างนั้นคีย์และข้อมูลแบรนด์ของคุณจะติดไปถึงนักเรียนทุกคน · แก้ชุดเริ่มต้นเมื่อไหร่ ให้สร้าง zip ใหม่แล้วอัปโหลดแทนไฟล์เดิม

ไฟล์คอร์สทั้งหมด

สวิตช์ = แสดงให้นักเรียนเห็น · ลำดับ = เลขน้อยขึ้นก่อน

อัปโหลดสไตล์ใหม่

เลือก โฟลเดอร์แพ็ค ที่มี pack.json (เช่น packs/serum-quiz-ab) — ระบบอัปทุกไฟล์ขึ้นคลังแล้วลงทะเบียนให้อัตโนมัติ · รหัสซ้ำกับของเดิม = อัปเดตสไตล์นั้น · เลือกโฟลเดอร์ packs ทั้งก้อนก็ได้ (อัปทีละแพ็ค)

สไตล์ในคลัง

สวิตช์ = แสดงในหน้าคลัง · ลำดับ = เลขน้อยขึ้นก่อน (เท่ากันเรียงตามชื่อ)

การใช้งาน

นับทุกครั้งที่ Claude ของนักเรียนเรียกเครื่องมือในคลังแสง

เริ่มสอนคอร์สออนไลน์ (ทำตามลำดับ)

  1. ออกคีย์ — แท็บ “คีย์นักเรียน” ใส่ชื่อนักเรียน → กด สร้างคีย์ (คนละ 1 คีย์)
  2. ส่งคีย์ + ลิงก์เว็บให้นักเรียน — กดปุ่ม ข้อความ ข้างคีย์ แล้ววางส่งทางแชท (มีคีย์และลิงก์ลงทะเบียนให้ครบ)
  3. นักเรียนลงทะเบียนเอง — ใส่อีเมล รหัสผ่าน และคีย์ → ดูรายชื่อได้ที่แท็บ “นักเรียน” (ลืมรหัสผ่าน → กด ตั้งรหัสผ่านใหม่ ให้ได้เลย)
  4. อัปโหลดวิดีโอบทเรียน — แท็บ “บทเรียน” → กด แก้ไข ที่บทนั้น → เลือกไฟล์วิดีโอ (หรือวางลิงก์ YouTube/Vimeo) · ระหว่างอัปโหลดห้ามปิดแท็บ
  5. อัปโหลด zip ชุดเริ่มต้น — แท็บ “ไฟล์คอร์ส” → เลือกไฟล์ zip ที่สร้างใหม่ด้วย tools/pack_starter_kit.sh (ไม่ zip เอง)
นักเรียนเรียนที่หน้า “คอร์สของฉัน” และเชื่อมคลังแสงกับแอป Claude ได้จากหน้านั้น · หลังบ้านกับหน้าคอร์สใช้บัญชีเดียวกัน เข้าสู่ระบบครั้งเดียวพอ

วิธีใช้หลังบ้าน

  1. ออกคีย์ — แท็บ “คีย์นักเรียน” ใส่ชื่อ → สร้างคีย์ → กด ข้อความ เพื่อคัดลอกข้อความพร้อมส่งให้นักเรียน (มีคีย์ + ลิงก์ลงทะเบียน) · คอลัมน์ “บัญชีที่ใช้คีย์” บอกว่าคีย์ไหนมีคนใช้แล้ว ตัวกรอง “ยังไม่ถูกใช้” = คีย์ว่าง
  2. นักเรียนเชื่อมเอง — หลังลงทะเบียน นักเรียนกด “เชื่อมคลังแสงกับแอป Claude” ในหน้าคอร์สของฉัน (หรือหน้า connect.html)
  3. ระงับคีย์ — ปิดสวิตช์ (เปิดคืนได้) · ลบ = ลบถาวร · ตั้งวันหมดอายุได้ที่ปุ่ม แก้ไข
  4. เอานักเรียนออก — แท็บ “นักเรียน” → ถอดคีย์ หรือ ลบ (ค่าเริ่มต้น = ปิดคีย์ด้วย นักเรียนเอาคีย์เดิมกลับมาใช้ไม่ได้) · ลิงก์วิดีโอที่นักเรียนเปิดไว้แล้วยังดูต่อได้อีกไม่เกิน 3 ชั่วโมง ไฟล์แนบ/ไฟล์คอร์สไม่เกิน 1 ชั่วโมง แล้วจะหมดอายุเอง
  5. เพิ่มสไตล์ — แท็บ “สไตล์” → เลือกโฟลเดอร์แพ็ค (pack.json, ref.mp4, thumb.jpg, sheet.jpg, frames/, playbook.md, beats.json, transcript.json, audio.json, template/, examples/) → รอจนขึ้น ✓ · ไฟล์เกิน 50 MB ต้องย่อก่อน หรือใช้เครื่องมืออัปโหลดในเครื่อง
  6. ซ่อน/เรียงสไตล์ — สวิตช์ซ่อนจากหน้าคลังและจาก Claude ทันที · แต่ภาพปก คลิปตัวอย่าง (ref.mp4) และภาพตารางยังเปิดได้ถ้ามีลิงก์ตรง — สไตล์ที่ยังเป็นความลับห้ามอัปขึ้น หรือกดลบแทนการซ่อน · ช่องลำดับ: เลขน้อยขึ้นก่อน
  7. ดูการใช้งาน — แท็บ “การใช้งาน” ดูว่าใคร ใช้เครื่องมือไหน กับสไตล์ไหน กี่ครั้ง
